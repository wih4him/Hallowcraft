# Hallowcraft

A Halloween item pack for BEEmod, for Portal 2's Puzzle Maker.

**Work in progress.** Nothing has been released yet. This repository was started on Halloween 2026, and the first release will be posted under Releases when it is ready.

## What is coming

Seven logic parts for your test chambers:

- **Stack-o-Lantern**: a carryable block that lights up. It comes in five forms (a carved pumpkin, a pumpkin, a watermelon, a Black Forest cake and a block cake), chosen with the Cube Type. Each form presses the buttons that match its Cube Type. The lit watermelon fires its own laser straight up.
- **Adjustable Repeater** and **Boolean Comparator**
- **Redrock Torch** and **Light Torch**
- **Pulse Generator** (Pulser, Wave-Pulser and Short-Wave modes, each length set by its timer) and **True One-Shot**

## Requirements

- Portal 2
- BEEmod 4.46.1

## Installing (once released)

Download the `.bee_pack` file from Releases and put it in BEEmod's `packages` folder. Then restart BEEmod.

The concepts and models are inspired by Minecraft, but they are custom models with custom built-in logic specifically for Portal 2, and nothing was borrowed directly from Notch or Minecraft.
